Every game on this page is free software ("free as in freedom", and also free as in price). The source code is public under a recognized FLOSS license — GNU GPL, LGPL, BSD, MIT, or a similar approved license — so anyone may download, play, copy, share, and usually modify the game, forever, with no ads or tracking. Every official link below was live-checked at publication (see Verified links in our guide).

New to open-source games? Start with the Play Free Forever guide: how to install them, controller support, gift ideas, and what FLOSS licenses mean in plain English.
